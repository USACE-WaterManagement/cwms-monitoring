# CWMS Monitoring – Grafana Service

## Start the Service

To build and start Grafana (and supporting services), run:

```bash
docker-compose up --build
```

## Access Grafana

Once running, open:

```
http://localhost:8080
```

Default login:

- **User:** `admin`
- **Password:** `admin`

## Stop the Service

To stop and remove the containers, run:

```bash
docker-compose down
```
